# Security Policy

## Supported Versions

Only the latest released version of each Spartan Labs project receives security fixes. Upgrade
to the newest release before reporting.

## Reporting a Vulnerability

**Do not open a public issue for a security problem.**

Use the affected repository's private vulnerability reporting flow under **Security → Advisories
→ Report a vulnerability**. If private reporting is unavailable, email
<spartaksingh95@gmail.com> with `SECURITY` in the subject.

Include the affected repository and version, what an attacker can do, affected configuration,
and a minimal reproduction. Expect an acknowledgement within one week. After a fix is released,
the advisory is published with reporter credit unless anonymity is requested.
