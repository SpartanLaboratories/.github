# SpartanLaboratories/.github

This repository holds the default community health files of the Spartan Laboratories
organization, its policies, its design manifesto, the structure they are written in, and a public
copy of the Claude Code configuration its work runs under.

- [Policy](POLICY.md): what every repository of the organization meets.
- [Design Manifesto](DESIGN.md): what the organization's code aims to be.
- [Structure](Structure.md): how these pages are written and pointed at.
- [Contributing](CONTRIBUTING.md): issues, branches, commits, pull requests and merges.
- [The Claude Code configuration](claude/README.md): the public copy and what it holds.
